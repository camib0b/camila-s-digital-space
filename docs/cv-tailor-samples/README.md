# CV tailor sample outputs

Run live generation (requires `XAI_API_KEY` and `JEV_API_KEY` in the environment):

```bash
export XAI_API_KEY=...
export JEV_API_KEY=...
npm run test:cv-live
```

This writes PDFs and Jev verdict markdown tables for the Buk and Falabella LinkedIn postings into this directory.
